# 项目文档索引

| `worknow.md` | 当前唯一执行焦点、阻塞项与下一条命令 |

| `experiment-log-template.md` | 新实验统一模板 |

| `repository-hygiene-audit.md` | Git 资产边界审计与清理选项 |

项目内容以本仓库证据为准。文档只引用可定位的代码、配置、manifest、结果摘要或外部原始来源。
