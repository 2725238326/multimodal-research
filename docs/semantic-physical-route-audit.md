# 语义—物理研究路线审计

**日期：2026-07-21**  
**状态：Completed（路线审计）；候选实验均未启动**

## 1. 核心判断

“用多模态大模型语义帮助物理特征识别”不是整体错误，但原始形式过于宽泛。它至少分成五条不同路径：

| 路径 | 判断 | 原因 |
| --- | --- | --- |
| 语义直接替代物理测量 | No-Go | 容易学习对象—属性共现，无法处理伪装、反常材料和尺度/几何歧义 |
| 语义与物理图直接拼接给冻结 VLM | No-Go | 本仓库 RGB+albedo 与共同框已显示无跨模型稳定收益 |
| 语义提出候选，物理证据验证 | Go | 语义缩小搜索空间，物理分支保留否决权 |
| 物理结构定位，语义稀疏解释 | Go | dense geometry/vision 负责边界，VLM/CLIP 负责命名与属性 |
| 训练期多物理模态教师，部署期单 RGB 学生 | Explore | 最符合本仓库条件，但须先证明 teacher 强于 RGB |
| agent 主动选择下一次物理测量 | High-risk Explore | 仅在静态观测确实不可辨且动作有执行式反馈时成立 |

更准确的原则是：

> 语义适合提出、约束、路由和解释；物理证据负责测量、校准、证伪和最终物理 claim。

## 2. 为什么原始方式容易失败

### 2.1 语义与物理真值不是同一随机变量

“杯子”提高 glass/plastic 的先验概率，却不能决定这个杯子实际是哪种材料；“地面”提示支撑关系，却不能证明两个实例接触。语义可以缩小候选集，不能提供未观测的反射、深度、接触或介电常数。

### 2.2 物理辅助图可能删除判别信息

albedo 更接近稳定漫反射，但 glass、metal、clear plastic 的判别信息大量存在于高光、透明、反射和随光变化的响应中。要求模型完全忽略光照可能同时删除任务信号。

### 2.3 冻结 VLM 没有学会新模态接口

额外输入被模型“看到”不等于被正确解释。共同框改变大量答案但没有形成稳定收益，说明接口对齐只是必要条件之一。

### 2.4 模态强弱按样本变化

RGB、albedo、depth、radar、touch 和语义并不存在全局固定排序。固定拼接把弱证据也强制注入，容易负迁移。

## 4. 推荐主线：不变身份—光响应因子化

### 研究问题

当 albedo 更稳定却判别力更弱时，能否把同一区域多光照观测分解为：

1. 跨光保持的材质身份；
2. 对材质有判别力的光照响应；
3. 文本对齐的语义属性；

再由可靠性门控把多光 teacher 的知识迁移给单 RGB student？

### 为什么仍有空间

相邻工作分别覆盖不变先验、语义融合、多编码器和选择性 KD，但尚未闭合本项目特有的矛盾：

- 不是只恢复正常光语义；
- 不是只生成或估计 albedo；
- 不是把光照变化全部视为噪声；
- 核心 claim 是“材质身份由不变部分和受光响应共同决定”，并研究如何选择性迁移到单 RGB。

### 最小 gate

在固定 scene split 上，用同容量浅层头比较：

1. 单 RGB patch feature；
2. 多光 feature mean；
3. mean + variance；
4. mean + pairwise response；
5. RGB + albedo；
6. RGB + albedo + RGB/albedo residual。

至少使用 DINOv3 和 SigLIP 两类特征。先判断多光响应是否提供超出不变均值的额外信息，再决定是否蒸馏。

### 必须控制

- 打乱同一区域的光照配对；
- 错区域 albedo；
- 随机 residual；
- 普通 consistency training；
- 朴素 KD；
- 同参数量额外分支；
- 按场景而非图片 bootstrap。

## 5. 邻接方向 A：语义提案—光学验证材质识别

VLM 只产生候选材质及可观察属性，例如：

- opaque / transparent；
- diffuse / specular；
- smooth / textured；
- conductor-like / dielectric-like。

物理验证器使用：

- RGB/albedo residual；
- 跨光 feature response；
- 高光移动和强度变化；
- 可选 polarization/radar/touch。

冲突时允许拒答、降级到上位光学家族或请求额外观测。研究重点不是平均融合，而是“哪种证据能推翻语义先验”。

**Go 条件**：在故意违反对象—材质常识的 counterfactual 子集上，物理验证显著纠正 VLM 候选。  
**No-Go**：增益只出现在常见对象—材质组合，或物理分支无法推翻错误先验。

## 6. 邻接方向 B：结构引导的物理关系 Agent

适合 NYUv2/3D 场景的候选结构：

```text
语义模型提出对象与候选关系
  → depth/segmentation 建结构单元
  → 几何程序验证接触、上下、重叠和支撑链
  → agent 只在冲突时选择新视角/工具
  → 输出关系及可定位证据
```

它与“把 support 标签写进提示”不同：语义只产生需要验证的假设，几何程序必须能够否决。当前 NYUv2 资产链未闭合，因此该方向保持 `Blocked`，先不运行。

## 7. 高风险方向：主动反事实光照 Agent

agent 根据当前材料后验选择下一种真实或生成式光照，以最大化信息增益；观察新图后更新候选并决定停止。

必须按以下顺序：

1. 在真实 25-light 数据上验证选光策略；
2. 比较固定、随机、贪心和 oracle 选光；
3. 只有真实数据成立后才接生成式 relighting；
4. 生成图须通过身份、几何和物理一致性检查。

经典主动照明已存在，因此创新不能是“选择光源”，而应是可校准的生成式干预、信息增益策略和对生成幻觉的物理验证。

## 8. 方向组合与当前优先级

| 槽位 | 方向 | 状态 | 进入条件 |
| --- | --- | --- | --- |
| 主线 | 不变身份—光响应因子化 + 特权蒸馏 | Proposed | Phase 0/1 完成；多光 response probe 通过 |
| 邻接 1 | 语义提案—光学验证 | Proposed | 构造反常对象—材质或冲突子集 |
| 邻接 2 | 结构引导的物理关系 agent | Blocked | NYUv2/3D 数据与许可闭环 |
| 高风险 | 主动反事实光照 agent | Exploration | 真实光照选择先显著优于固定/随机 |

不并行训练四条路线。每次最多一个主线实验和两个 1–2 天 gate。

## 9. 最终决策

- 原始“冻结 VLM + 物理辅助图直接提示”保持 `No-Go`。
- “VLM 语义直接预测物理真值”不作为新路线。
- “语义提案—物理验证”“物理结构定位—语义解释”和“特权物理教师—单 RGB 学生”进入候选模式。
- 当前最优先的新问题是验证光响应是否含有超出光照不变表示的材质信息。
