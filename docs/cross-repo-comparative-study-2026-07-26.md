## 3. 两条独立线共享的深层机制

这是对照研究最有价值的发现。两条线的对象不同（材质 vs 深度支撑关系），但失败模式高度同构：

1. **精细结构不敌朴素/规则基线**：本 fork 的响应描述符被朴素平均支配；Summer 的图网络/结构化边（39.9%）被深度差规则（60.9%）支配。两边都是"更复杂的方法在两个轴上不优于最简单的对照"。
2. **对照/规则超越主方法**：本 fork 第四轮打乱与 exposure-only 高于主方法；Summer 关系头全部低于深度差规则。都指向主方法没有取用到宣称的信息。
3. **语义/外观统计不能替代物理测量**：本 fork 证明跨光照外观统计不携带可迁移材质信息、探针归一化不可定义；Summer 证明单帧深度对象对不足以学出支撑依赖、文字化物理先验无增益。
4. **接口保留但研究收益否决**：Summer 保留 DPE/ROI 作为工程接口但否决其研究收益；本 fork 保留 response 作为潜在不确定性信号但否决其分类/拒判用途。两边都区分了"接口可用"与"机制成立"。

**可合并的论点**：在冻结/浅层接口下，把语义或外观统计当作物理量的替代，在材质与深度两个独立任务上都被最朴素的基线支配。这比任何一条线单独的负结果都更有说服力，因为它跨任务、跨团队、跨模态。
