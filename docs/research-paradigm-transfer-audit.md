# 研究范式迁移审计

**日期：2026-07-21**  
**状态：Completed（流程审计）；不构成新实验立项**

## 1. 结论

旧工作区中可以迁移的是研究治理与证伪方法，不能迁移的是研究事实、结论、优先级、数据、代码和项目状态。

本仓库已经具备实验计划、证据状态、独立统计单元、Go/No-Go 和 Git 边界等基础。值得补强的部分是：

1. 查新从“列论文”升级为“结论级碰撞检查”；
2. 正式训练前增加 oracle / frozen-feature gate；
3. 每个多模态干预都加入错误、反向、无关或随机线索控制；
4. 把 agent 视为可审计的工具编排层，而不是默认能修复视觉表征缺陷的模型升级；
5. 先证明视觉证据有效，再进入 projector、adapter、LoRA 或 agent 系统。

## 2. 隔离边界

| 可以参考 | 不得进入本仓库事实链 |
| --- | --- |
| 文档结构、实验模板、状态定义 | 旧工作区的研究结论和方向排序 |
| oracle gate、停损条件、反证控制 | 旧工作区的数据、标签、运行结果 |

所有迁移项都必须重新绑定本仓库自己的研究问题、数据许可、独立统计单元、模型版本和失败证据。即使两个工作区出现相似主题，也不能把旧工作区的结论当作本仓库实验结果。

## 3. 对本项目的适配

### 3.1 可直接采用

- **预注册研究合同**：问题、可证伪假设、最近工作、Go/No-Go、资源上限在运行前写入 `experiments/plans/`。
- **证据阶梯**：数据审计 → 极小 smoke test → frozen-feature gate → 受控训练 → 外部验证 → VLM/agent 接入。
- **反证优先**：正确线索必须与错误、反向、随机或无关线索形成方向一致的差异，避免把提示长度、额外像素或答案泄漏误写成机制收益。
- **独立单元统计**：材质恒常性按 scene / region 配对统计，不能把同一区域的多次照明观测当成独立样本。
- **停止条件**：主指标置信区间跨零、保护指标恶化、简单基线解释全部收益或跨模型方向不一致时停止扩大。

### 3.2 需要改写后采用

| 旧范式中的通用做法 | 本仓库中的改写 |
| --- | --- |
| 冻结模型 oracle 提示 | 先验证目标区域证据本身是否含信息，再比较 RGB、albedo、融合和错误证据 |
| 多模态线索转文本 | 必须同时比较原始模态、数值/规则基线和无答案泄漏的短证据 |
| 多模型复核 | 至少覆盖不同视觉编码/连接机制，不能只换同一家族尺寸 |
| agent 调用视觉工具 | 与固定流水线、单模型和规则程序比较，并记录工具选择正确率、任务成功率、失败恢复、成本和时延 |
| LoRA/adapter 扩展 | 只有 frozen-feature 或小头 gate 通过后才准入 |

### 3.3 不建议迁移

- 不把“多模态”“agent”或“更大模型”本身当作创新点；
- 不把 oracle 真值提示的提升写成自动系统能力；
- 不在当前 RGB+albedo 与共同区域标记已为 `No-Go` 的条件下继续堆叠相似提示元素；
- 不在环境锁定、数据许可和 scene-level 划分补齐前启动大规模训练；
- 不以 Gemma、Qwen、InternVL 等模型家族的更换代替机制假设和对照设计。

## 4. 建议的研究推进阶梯

以下是候选协议，不是已批准实验。

### Gate A：复现与数据闭环

- 固定环境、数据来源/许可、manifest hash 和 scene-level split；
- 用同一小型 manifest 复跑现有 RGB 基线；
- 检查区域标签、mask、配对照明和类别分布。

**退出条件**：聚合结果可复现，且不存在明显的数据泄漏或独立单元错误。

### Gate B：视觉机制定位

- 在同一 mask / region 上比较 CLIP/SigLIP、DINOv2/DINOv3 等冻结特征；
- 使用同容量线性头或浅层 MLP，分别测 RGB、albedo 和融合；
- 主指标至少包括 accuracy、macro accuracy、paired flip rate、worst-light accuracy 和 scene-level bootstrap CI。

**Go 条件**：融合或目标机制同时改善判别准确率与跨光稳定性，且不能被单一强视觉基线解释。  
**No-Go 条件**：只有稳定性改善但判别力下降，或 CI 跨零、跨模型方向不一致。

### Gate C：选择性训练期辅助模态

仅在 Gate B 通过后，测试训练期可见、推理期 RGB-only 的选择性蒸馏或可靠性门控。必须比较普通监督、一致性训练、朴素 KD、选择性 KD、随机/错误辅助模态和去门控消融。

### Gate D：VLM 与 agent

- 先冻结 LLM，仅测试 projector/adapter 是否保留 Gate B/C 的视觉收益；
- agent 仅用于调用区域提取、深度/分割、检索或验证工具；
- 与固定工具流水线比较，任务必须需要组合或恢复能力，否则 agent 层没有研究必要。

## 5. 当前决策

- **流程迁移：Go**。迁移证据阶梯、反证控制、停损条件和协作记录方式。
- **研究内容迁移：No-Go**。旧工作区的任务、结论、数据和代码不进入本项目。
- **立即训练新模型：Blocked**。仍受 Phase 0/1 的仓库治理、环境锁定、数据许可和复现门禁约束。
- **文献基线：Completed**。首批索引见 `literature/paper-index.md`；PDF 为本地忽略资产。
